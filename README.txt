OVERLOAD V1

A local-first progressive overload workout tracker.

QUICK START
1. Extract the ZIP.
2. For a quick laptop preview, open index.html in Chrome/Edge.
3. Workout data is saved in the browser using localStorage.

PHONE / INSTALLABLE APP
A PWA must be served from HTTPS (or localhost) for installation/offline features. Upload this folder to a simple static host such as GitHub Pages, Netlify, Cloudflare Pages, or Vercel. Then open the HTTPS address on your phone and choose Add to Home Screen / Install App.

IMPORTANT
Data is currently stored only in the browser/device where you use the app. V2 can add account/cloud sync.
